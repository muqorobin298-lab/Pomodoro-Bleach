# Pomodoro Bleach ⚔️

Timer Pomodoro bertema anime Bleach, dibuat pakai HTML, CSS, dan JavaScript.

🔗 **Coba di sini:** https://muqorobin298-lab.github.io/Pomodoro-Bleach/

## Fitur
- Mode Fokus (25 menit), Istirahat (5 menit), dan Istirahat Panjang (15 menit)
- Latar anime berubah sesuai progres, sampai BANKAI!
- Bunyi bip saat waktu habis
- Hitungan sesi fokus harian tersimpan di browser
- Sisa waktu tampil di judul tab
